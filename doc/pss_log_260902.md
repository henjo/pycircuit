

### 2026-09-27 — refactor phase 3: the noise-source layer, bit-identical part

**Order: de-silence the seams first.**  Several tests patch a helper on
the instance and assert equality with the unpatched path.  If a
refactor stops the lookup going through the instance, such a test passes
VACUOUSLY.  Each now records that its patch was consulted:
- covariance: `_separable`;
- sampled: `_leaf_access`, `_cached_root`;
- pnoise: `_cy_colour_model`;
- the frequency-aware PPV: `_equation_row_blocks`;
- the lineshape: `FA_RHO_FIT`, which asserts `lineshape_info['rho_fit']
  == 'chebyshev'`.

The remaining patches already fail visibly: `_colour_fit` requires a
difference, and `_separable` in the sampled test counts CY calls.

**1. The sample series takes `_colour_groups`.**  Three of the four
root consumers now share one construction: `sampled_noise` /
`sampled_variance`, the modal spectra and the modulated fold.  Kept
bit-identical:
- the FIXED groups are summed before the BAND ones, which is the series'
  own order;
- `_colour_groups` caches every band root per frequency (`_cached_root`),
  as the series did; it was uncached for the other consumers;
- the zero-touch warning, which the series never gave, is a flag
  (`warn_touch`).  Its CY evaluation now runs only when it can warn.

Recorded on the four consumer files: 4442 pac and 396 pss calls identical,
0 warnings moved.

**2. `_coloured_covariance`'s column response, once.**  Four closures
pushed unit columns through the response.  The power-law, separable and
non-separable (per column, per band) terms now share one `column_ev`; the
separable shape scale is evaluated first, as before.  The inline
rank-revealing SVD was `reduced()` written out.  51 lines became 38.  The
covariance, oscillator-covariance and events files: 154 pac and 225 pss
calls identical.

**3. The ONE element, not every element.**  The cyclostationary fold's
per-band group read `_element_cy_samples(pss, w)[key]`.  That evaluates
every element at every point for every band, then keeps one.  It took 48
of 110 s (profiled) on the MOS stage's Lorentzian test.
`_one_element_cy` is the same array bit for bit, so the test went 65.7 ->
42.8 s, all 128 pac calls of the pnoise file identical.  The stationary
per-band term of the covariance did the same per band frequency at one
state; it is changed too (covariance file identical).

**Not done, and why.**
- The PPV-quadrature helper: the four sites each carry the history of a
  bug particular to that site (`tms[:n]`, the samples' own period), and
  the helper would save about 15 lines.
- `_colour_fold`'s three closures: `coloured` precomputes each group's
  harmonic powers, and merging it with `resolved_fa` would recompute them
  per offset.
- The "not the sum of its elements" refusals end differently; each
  names its own remedy.
- One classifier and one warning policy: the per-band sampler never uses
  signed amplitudes and never warns, while `_coloured_prepare` does both;
  their probe sets differ.  Unifying them CHANGES behaviour, which the plan
  leaves to Andreas.
- `_cyclostationary_fold` onto the groups (amplitude to power scaling, the
  batched root) changes numbers at ~1e-16 and the speed win is taken by 3
  without it.
