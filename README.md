# pycircuit

Python circuit design and simulation tools.

## Install

```bash
pip install -e ".[dev]"
```

## Documentation

Built with Sphinx. To build locally:

```bash
pip install -r doc/requirements.txt
make -C doc html
# output in doc/build/html/
```

Hosted on GitHub Pages: https://henjo.github.io/pycircuit/

## Tests

```bash
pytest
```
